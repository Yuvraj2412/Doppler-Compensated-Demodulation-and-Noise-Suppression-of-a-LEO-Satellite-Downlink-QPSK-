# Doppler-Compensated Demodulation and Noise Suppression of a LEO Satellite Downlink (QPSK) in MATLAB

DSP course project, IIST (B.Tech ECE, Avionics) - Yuvraj Singh Tomar (SC24B137), submitted to Prof. R. Lakshminaryan.

A complete digital receiver for a QPSK/OQPSK satellite downlink, built and validated in stages: first on a
controlled simulated link (AWGN, Doppler S-curve, timing and clock error, tone interference), then on a real
Meteor-M LRPT recording at 137.9 MHz (carrier/Doppler tracking, EVM, Viterbi decoding, frame sync, frame headers).
The full write-up is in **`Final_Report.pdf`**; the approved proposal is also included.

## Repository contents

`stage4e_pass_sync_stats` and `stage4f_frame_headers`.

## Requirements
MATLAB (no toolboxes required; `resample` is used if available, otherwise a spline fallback). The simulation
scripts were also tested in GNU Octave.

## Data (not included)
The real-data stages use one raw IQ recording, `LRPT_16-29-02_137900kHz.wav` (105.4 s, 187.5 kSa/s, 2-channel
16-bit), taken from the I/Q-recording link on the SigIDWiki page *Low Rate Picture Transmission (LRPT)*
(<https://sigidwiki.com/wiki/Low_Rate_Picture_Transmission_(LRPT)>). It is **not** redistributed in this repository.
Download it yourself and place it in the MATLAB current folder (or set the full path in the `file = ...` line of
each real-data script). `meteor_bb.mat` (baseband at 576 kS/s) is generated by Stage 4a and is not committed
because of its size.

## How to run
In MATLAB, change into the code folder and run the scripts in this order:
```matlab
cd 'MATLAB Code'
stage1_clean_link          % clean QPSK + AWGN, BER vs theory, PSD, eye
stage2_doppler_sync        % Doppler S-curve, timing and clock error, full sync chain
stage3_interference        % tone interferer; IIR notch, FIR band-stop, NLMS canceller, NLMS line enhancer
stage4b_oqpsk_sim          % OQPSK receiver validated in simulation
oqpsk_doppler_rate_test    % fast vs slow Doppler and loop bandwidths (report Table 4; takes several minutes)
% --- real data (needs the .wav file) ---
stage4a_inspect_real       % load IQ, find band, baseband + resample, saves meteor_bb.mat
stage4c_real_receiver      % QPSK/OQPSK and roll-off comparison by EVM
stage4d_full_pass          % whole-pass Doppler and EVM
stage4d_decode_check       % Viterbi + sync marker on one segment
stage4e_pass_sync_stats    % sync statistics across the pass
stage4f_frame_headers      % de-scrambling and VCDU header check
```
Stages 4c-4f need `meteor_bb.mat` in the current folder, so run `stage4a_inspect_real` first. The simulations use
fixed random seeds, but MATLAB and Octave generate different random numbers, so low-SNR BER values can differ
slightly between them (the report's numbers come from MATLAB).

## Headline results
| Experiment | Result |
|---|---|
| QPSK over AWGN with RRC pulses | BER follows theory (0-9 dB) |
| Doppler S-curve + 0.3-symbol timing offset + 20 ppm clock error | Within a fraction of a dB of ideal AWGN (4-8 dB) |
| Tone interferer, SIR -10 dB, E_b/N_0 = 10 dB | No suppression: BER 0.5; IIR notch: 0 errors in 8.8e4 bits; NLMS canceller: 2.3e-5; FIR band-stop: 1.5e-4; line enhancer: 2.4e-2 |
| OQPSK receiver (simulation) | About 0.6-0.8 dB from theory with a 150-200x compressed Doppler; matches theory at 6 dB with a slower Doppler |
| Real recording: modulation | QPSK (EVM 27.7 % vs about 49 % for OQPSK) |
| Real recording: whole pass | All 26 chunks locked, median EVM 17.8 %; carrier drift -2329 Hz over 100 s, max 27.3 Hz/s |
| Real recording: decoder checks | Frame sync in 35 of 35 segments; 244 frame headers with constant IDs; frame counter rate 8.789 frames/s (nominal 8.789) |

## Scope and limitations
- Real-data results come from one QPSK recording (probably Meteor-M N2; satellite identity inferred, not confirmed).
  The OQPSK receiver is validated in simulation only.
- Reed-Solomon decoding and image reconstruction were not implemented; the decoder checks stop at frame headers.
- The simulated Doppler is compressed to about 150-200x the real rate to keep run times short.
- See the report for details, caveats and the AI-tool-use statement.
